# Pulsioxímetro (MATLAB + Arduino)

Proyecto de pulsioxímetro con doble LED (rojo e infrarrojo). El código de MATLAB procesa la señal capturada, muestra la gráfica en tiempo real y calcula la frecuencia cardíaca y la saturación de oxígeno (SpO₂). El código de Arduino controla la conmutación entre luz roja e infrarroja y adquiere los datos del fotodiodo.

## Archivos
- pulsioximetro.m — Procesado de señal, HR y SpO₂
- pulsioximetro.ino — Control de LEDs y lectura del sensor

## Tecnologías
MATLAB, Arduino
